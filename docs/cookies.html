Cookie policy

Last updated November 7, 2026

This website does not set cookies and does not use any tracking technology, such as analytics, advertising pixels or fingerprinting. That is why there is no cookie banner.

The site loads no third-party scripts or fonts. Everything is served from GitHub Pages, which hosts the site. GitHub's own cookie practices are described in the GitHub cookies statement; GitHub Pages sites like this one do not set cookies for visitors.

The Treymark desktop app and browser extension do not use cookies or tracking either. The extension stores nothing in your browser; notes are saved by the desktop app in your project folder.

Downloading from GitHub Releases happens on github.com, which has its own policies.

If this ever changes, for example if analytics are added, this page will be updated first and any cookies that need consent will ask for it.
