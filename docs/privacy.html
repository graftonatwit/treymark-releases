Privacy policy

Last updated November 7, 2026

Short version: Treymark runs on your computer and does not collect your data. This website has no analytics and sets no cookies.

This policy covers the Treymark desktop app, the Treymark browser extension, the Treymark agent skill, and this website. Treymark is made by Trevor Grafton ("I", "me").

The Treymark app and extension

What stays on your computer

  • Notes. Each note stores the text you write, the page address, a CSS selector, a short description of the element (tag, classes and visible text) and its position. Notes are saved in a .treymark folder inside your project.
  • Project list. The folders you add are saved in the app's settings folder on your computer.
  • Agent token. A random token in .treymark/token lets your coding agent connect to the app.
  • Notes folder (optional, off by default). If you choose a notes folder, finished notes are saved there as Markdown files, with screenshots of the noted area before and after the change. Screenshots are taken by loading your localhost page in a hidden window on your computer; only localhost pages are ever loaded. Your agent may read this folder to learn your preferences.

What is sent to me

Nothing. The app and extension have no accounts, no analytics, no crash reporting and no telemetry. They do not send notes, code, page content or usage data to me or anyone else. The only network request the app makes is the update check described below.

How the parts talk to each other

The app runs a small server that listens only on 127.0.0.1 (your own computer). The extension and the script tag send notes to it from localhost pages. Your coding agent reads and answers notes through it using the private token. None of this traffic leaves your computer.

Update checks

Every few hours the app asks GitHub whether a newer release of Treymark exists, and downloads it from GitHub if so. Like any web request, GitHub sees your IP address. Nothing about you, your projects or your notes is sent.

Your coding agent

When your agent reads a note, the note becomes part of that agent's session. Your agent provider (for example Anthropic, OpenAI or Cursor) handles that data under its own terms and privacy policy, not this one.

Extension permissions

The extension only runs on localhost and 127.0.0.1 pages. It does not read your browsing history and does not run on other websites.

This website

This site is hosted on GitHub Pages and the downloads are hosted on GitHub Releases. I do not run analytics or tracking on it and it sets no cookies. GitHub, as the host, may log technical data such as your IP address when you visit or download, as described in the GitHub General Privacy Statement. I can see aggregate download counts for each release, which do not identify you.

If you open an issue on GitHub, your GitHub username and what you write are public on GitHub.

Children

Treymark is a developer tool and is not directed at children under 13.

Changes

If this policy changes, I will update the date above and note the change in the release notes.

Contact

Questions about privacy: open an issue.
