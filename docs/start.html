Getting started

About two minutes from download to your first fixed note.

InstallPick a projectAdd to your page Connect your agentFirst noteTroubleshooting

1. Install

  1. Download Treymark-Setup-<version>.exe from the latest release.
  2. Run it, accept the license, and choose where to install. No admin rights are needed.
Treymark is not code signed yet, so Windows may show "Windows protected your PC". Click More info, then Run anyway. Each release lists a SHA-256 checksum if you want to verify the download.

2. Pick your project

Open Treymark and click Choose project folder. Pick the root folder of the web app you are working on. Treymark starts its local server for that project and keeps notes in a .treymark folder inside it. Add .treymark/ to your .gitignore.

You can add several projects in the sidebar and click one to switch. One project is active at a time. Closing the window keeps Treymark running in the system tray; quit from the tray icon.

3. Add Treymark to your page

Chrome extension (recommended)

The extension adds Treymark to every page on localhost or 127.0.0.1, so your project needs no changes. It works in Chrome and Edge.

  1. Open chrome://extensions (or edge://extensions).
  2. Turn on Developer mode.
  3. Click Load unpacked and choose the extension folder. The Connect agent tab in the app shows its path. With the default install it is:
%LOCALAPPDATA%\Programs\Treymark\resources\extension

Script tag

For other browsers, or if you prefer no extension, add the tag from the Connect agent tab to your app during development only. It usually looks like this (the port can differ if 4747 was busy):

<script src="http://127.0.0.1:4747/overlay.js"></script>

4. Connect your agent

Open the Connect agent tab. It shows ready-to-copy setup for Claude Code, Codex, Cursor and any agent with a shell, already pointing at your project and at Treymark's built-in runtime. You do not need Node installed.

Claude Code example (the app fills in your real paths):

claude mcp add treymark -s user cmd /c "...\Treymark\resources\bin\treymark.cmd" "mcp" "C:\path\to\your\project"

Start a new agent session afterwards so it loads the Treymark tools.

Install the skill

In the same tab, click Install for Claude Code. The skill teaches your agent the note loop. For Codex, Cursor and others, copy the instructions into your AGENTS.md or rules file.

5. Your first note

  1. Open your app on localhost and press Alt+A (or click the note button in the bottom right).
  2. Click an element, or drag a box over an area.
  3. Type what should change and press Ctrl+Enter. A pin appears on the element.
  4. Tell your agent: "check my Treymark notes".
  5. Watch the pin change color. Click it to read the reply, and reply again to keep refining.

What the pin colors mean:

  • Blue, Waiting for agent: sent, not picked up yet.
  • Amber, Agent working: your agent claimed it.
  • Purple, Needs your reply: your agent has a question. Answer on the note.
  • Green, Done: changed. Reply to reopen it if it is not quite right.

Troubleshooting

"Ports 4747-4756 are all busy"

Treymark uses the first free port from 4747 to 4756 and the extension and your agent find it automatically. This message means all ten are taken by other local servers. Close some of them, then click your project in the sidebar again.

The note button does not appear

Treymark only runs on localhost and 127.0.0.1 pages. Check that the extension is enabled, reload the page, and make sure Treymark is open with a project selected.

My agent says the server is not running

Open Treymark and select the project. Your agent talks to the app, so it needs to be running.

The agent does not see Treymark tools

Start a new agent session after adding the MCP setup. In Claude Code, run /mcp to check that treymark is connected.

Updates

From version 0.2.0, Treymark checks for updates every few hours. When one is ready, click Restart to update in the sidebar or the tray menu. If you have 0.1.x, download the latest installer once. After an update, open chrome://extensions and click the reload icon on Treymark so the extension picks up the new version.

Start with Windows

Off by default. Turn on Start with Windows in the sidebar to have Treymark start in the tray when you sign in.

Uninstall

Use Windows Settings > Apps. Your notes stay in each project's .treymark folder until you delete them.
