What these numbers mean

  • They are GitHub's own download counters for each file on the releases page.
  • Installed copies of Treymark download new versions from the same place when they update, so one person can add several downloads over time. Read these as "how much has been downloaded", not "how many people".
  • Site visits are not counted. This website has no analytics and sets no cookies, on purpose. See the privacy policy.
